# Career Analysis Skill

Career Analysis Skill 是一个面向求职者的职业分析 Skill。它会从你过去真实留下的工作文件中寻找职业证据，重新梳理你做过什么、真正积累了哪些能力，以及哪些优势可能一直被你忽略或低估。

你不需要先回忆几年前每个项目发生过什么，也不需要把庞大的历史文件夹重新阅读、去重、分类、编号。Skill 会先从已有工作资料中筛选有分析价值的内容，构建 **Career Evidence Package（职业证据包）**，再基于这些真实经历分析能力长板、能力短板、职业方向和职业定位。

**当前版本：Public Beta**

## 为什么需要它？

今天用 AI 写简历、润色经历、针对 JD 调整表达，已经是很自然的求职过程。把自己呈现得更清楚、更有竞争力，本身没有问题。

但大多数简历优化都有一个天然限制：它主要基于**你已经想起来并写进简历的内容**继续工作。

工作几年以后，我们往往已经记不清很多项目的细节。某个当年花了几个月解决的问题、一次复杂的跨团队推进、一套自己逐渐摸索出来的方法，今天可能只剩简历上的一句话，甚至根本没有被写进去。与此同时，大量真实的工作痕迹其实还留在项目方案、汇报材料、复盘、数据文件、会议记录、计划表和交付文件里。

这些文件能够帮助你重新看到一些单靠回忆很容易遗漏的东西：你曾经反复解决过什么问题，别人为什么把某些任务交给你，你在哪些环境里表现稳定，哪些能力已经在多个项目中出现，只是过去从来没有被你当作自己的职业优势。

Career Analysis Skill 想做的，就是把这些沉睡在历史文件里的职业信息重新找回来。

## 它怎么工作？

简历可以提供，但它不是分析的中心。简历更像是“你目前如何描述自己”的一份参考，而真实工作文件提供了另一层信息：**过去实际发生过什么。**

你可以直接从保存多年的工作文件夹开始，不需要提前替 Skill 挑出所谓“最重要的几个项目”。它会先筛选资料，识别更有职业分析价值的文件，并逐步建立 Career Evidence Package。

```text
历史工作文件
    ↓
筛选有效材料
    ↓
Career Evidence Package
    ↓
还原项目事实与个人贡献
    ↓
识别反复出现的能力证据
    ↓
分析能力结构、职业方向与定位
```

这里的 Career Evidence，并不是看到文件里出现一个结果就直接归到个人头上。工作文件比今天重新回忆往事保留了更多现场信息，但它也可能记录团队成果、缺少上下文，或者无法证明某项工作究竟由谁主导。因此 Skill 仍会尝试区分参与与主导、团队成果与个人贡献，以及“出现过某项工作”和“已经形成稳定能力”之间的差别。

它追求的不是给你拼出一个尽可能漂亮的职业形象，而是尽量从真实经历里找到一个**更完整的你**。

## 最终你会得到什么？

完成分析后，Skill 会基于 Career Evidence Package 生成一份完整的职业分析报告。它不会只是重新复述你的工作经历，而是把分散在不同项目和文件中的信息重新组织起来，帮助你看清自己的职业积累。

报告主要包括：

* **职业经历与核心项目梳理**：识别真正构成你主要职业积累的经历和项目。
* **核心能力与职业证据**：说明能力判断来自哪些真实经历，而不是只给出一个能力标签。
* **能力长板**：找出在不同项目中反复出现、已经形成相对稳定优势的能力。
* **被低估的能力**：发现真实工作中已经多次体现，却很少被你写进简历或主动总结的能力。
* **能力短板与证据缺口**：判断哪些方向目前积累较弱，哪些能力还缺少足够经历支撑。
* **能力结构与可迁移能力**：分析过去积累中哪些能力可以迁移到新的岗位或职业方向。
* **职业方向与岗位定位**：结合现有经验和能力结构，分析更值得重点考虑的职业方向及其匹配程度。
* **简历校准**：如果同时提供简历，会进一步判断当前简历是否遗漏、低估或没有准确表达真实能力。

这里并不是为了专门“找短板”。很多时候，更有价值的结果恰恰是发现：**你实际拥有的东西，比你今天能够回忆和表达出来的更多。**

这份报告可以继续作为后续修改简历、选择岗位、判断职业方向和准备求职材料的基础。

## 它在求职过程中什么时候有用？

**场景一：重新修改简历之前。**

先从真实工作经历里重新认识自己的能力，再决定什么值得写、什么应该成为核心卖点，以及接下来应该把自己定位到哪里。

**场景二：简历工具已经帮你优化过简历之后。**

此时不是为了否定润色，而是把这份更成熟的简历重新放回真实职业经历中看看：还有没有重要能力被遗漏？工具是否只能围绕现有文字进行了延伸，而历史项目里其实存在更值得表达的内容？现在呈现出来的职业形象，是否已经抓住了你真正有竞争力的部分？

所以它和简历优化工具并不是替代关系。一个负责让表达变得更好，另一个试图让你在表达之前，**拥有更多真实、具体、可追溯的东西可以表达。**

## 适合谁？

如果你工作了一段时间，电脑里已经积累了大量项目资料，却很难完整说清这些年究竟沉淀了什么，这个 Skill 会比较适合你。

它尤其适合正在求职、准备重写简历、考虑转岗转行，或者已经用 AI 优化过简历但希望重新梳理职业定位的人。

你不需要先做一套漂亮的项目案例集，也不需要专门花几天时间整理历史文件。已有的真实工作资料，本身就是分析起点。

## 当前测试状态

Career Analysis Skill 目前处于 **Public Beta**。

当前版本已经完成 Skill 安装、历史工作文件筛选、Career Evidence Package 构建、职业证据识别、能力分析、职业方向与职业定位等完整流程测试，并已经使用真实工作材料跑通端到端流程。

目前真实测试样本主要来自市场、公关、活动策划及相关职业经历，因此**跨行业泛化能力仍需要真实用户继续验证**。技术、产品、人力资源、财务、销售、供应链、设计以及其他专业领域目前都属于重要的待测试场景；英文工作材料和英文工作流同样需要进一步验证。

Public Beta 的目的并不是证明它一定适合所有职业，而是逐步找到这套基于真实工作证据的职业分析方式在哪些环境中有效，又在哪里存在边界。

## 安装

请下载完整仓库并保留目录结构：

```text
career-analysis-skill/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── evidence-framework.md
    └── report-outline.md
```

不要只复制 `SKILL.md`，`references` 中的文件属于完整分析流程的一部分。

当前版本已在 **Codex、WorkBuddy** 中完成安装和运行测试。其他支持 Agent Skills 的环境仍需要进一步验证。

## 隐私说明

真实工作文件可能包含客户信息、公司内部资料、商业数据、预算、合同或其他敏感内容。请根据自己的 AI 使用环境和组织规定决定哪些文件可以使用，以及是否需要提前脱敏。

**请不要把自己的简历或工作文件上传到本 GitHub Repository。**

如果你愿意参与 Beta 测试，不需要把任何原始资料交给项目作者。请在自己的环境中完成分析，只提交使用反馈即可。

## Feedback

Career Analysis Skill 目前仍在进行跨行业真实用户验证。如果你愿意参与测试，欢迎通过 GitHub Issues 告诉我：

* 你的行业、岗位和大致工作年限
* Skill 是否正确理解了你的工作
* 文件筛选结果是否合理
* Career Evidence Package 是否遗漏了重要项目
* 有没有把团队成果错误归因给个人
* 有没有发现过去被你忽略或低估的能力
* 能力长板、短板和职业定位是否符合真实情况
* 有没有出现缺乏证据的推断
* 最终报告中哪些部分最有帮助
* 哪些部分明显需要改进

**不需要提交你的简历、工作文件或完整分析报告。**

如果你来自目前尚未测试的职业领域，即使最终结果并不理想，这类反馈也非常有价值。Public Beta 的目的之一，本来就是逐步发现这套方法真正适合哪些职业，以及它的边界在哪里。
