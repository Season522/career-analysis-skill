# Report Outline

Use this outline only for the final user-facing `职业能力梳理与岗位定位报告`.

Do not create separate user-facing Stage 3 reports, Stage 4 reports, `v1`, `v2`, evidence drafts, or cross-validation versions. Internal analysis can be complex, but the user should receive one complete final report.

The outline is industry-neutral. Generate capability, role, project, and positioning language dynamically from the user's authorized evidence, latest resume, and necessary high-value clarifications.

## 1. 执行摘要 / 核心职业定位

Before stating the core positioning, explicitly state:

- Long-term career throughline
- Currently strongest-evidenced capabilities
- Whether they align or differ
- If they differ, their relationship, such as long-term career base plus later added capability layer

Then summarize the user's core career positioning, best-fit role direction, and major caveats. Do not let the most complete archive stage alone define the user's career base. The currently strongest-evidenced capability must not automatically become the core career positioning.

## 2. 职业经历主线

Describe the career timeline, work periods, role progression, recurring work contexts, duration of each major stage, and evidence coverage. Distinguish resume-provided chronology, portfolio evidence, user-confirmed context, and project-file evidence.

## 3. 稳定能力链

Identify the recurring chain of professional behaviors that appears across projects or time. Explain how the chain connects task source, user behavior, execution process, collaboration, delivery, and results.

If the long-term career throughline and the strongest-evidenced capability set differ because some stages have richer archives than others, state that distinction clearly and preserve both in the report.

## 4. 职业能力地图

Classify capabilities into:

- 已成熟、可直接作为职业卖点的能力
- 有价值但必须限定范围的能力
- 做过 / 接触过但暂不作为核心竞争力的能力
- `unknown / not evidenced`
- 明显能力缺口, only when explicit contrary evidence or target-role mismatch supports the gap

For each capability, state the evidence basis, attribution confidence, depth, boundary, and interview defensibility.

When a long-duration career stage has sparse raw files, lower evidence confidence if needed, but do not treat the capability or experience as absent solely because it is under-documented.

## 5. 代表项目

For each representative project, explain:

- What the project can prove about the user's behavior or capability
- What the project cannot automatically prove
- Which parts appear personal, team-based, client-provided, vendor/supplier-provided, mixed, or unclear
- Any version, attribution, or evidence caveats

## 6. 岗位定位

Analyze:

- 岗位类型
- 组织侧 / 工作环境
- 职责层级
- 匹配程度
- 判断依据

Explain why each role direction is supported, bounded, risky, or not yet evidenced.

Separate role directions supported by long-term career history from role directions supported by the strongest project-file evidence. Explain where they align or diverge. Do not let a short, well-documented stage override a longer career base without support from role chronology, stage duration, repeated responsibilities, resume timeline, and user-confirmed facts.

## 7. 求职方向分层

Group job-search directions by evidence fit, such as priority directions, adjacent directions worth testing, cautious directions, and directions not currently supported by evidence.

## 8. 用户可能高估与低估的能力

Identify capabilities the user may be overstating, understating, or naming imprecisely. Tie each point to evidence, resume wording, and attribution boundaries.

## 9. 下一阶段能力补强建议

Recommend practical capability strengthening only where evidence shows a real need, target-role mismatch, or clear growth opportunity. Do not invent gaps from missing evidence alone.

## 10. 简历定位与表达建议

Suggest evidence-safe resume positioning, claims to strengthen, bounded claims to word carefully, unsupported claims to avoid, and proven strengths that should be made more visible.

## 11. 面试职业叙事

Draft an interview narrative grounded in representative projects, personal behaviors, decisions, tradeoffs, outcomes, and lessons the user can defend under follow-up questions.

## 12. 当前职业决策原则

State practical decision principles for evaluating target roles, organizations, responsibility scope, growth tradeoffs, and evidence-aligned positioning.

## 13. 材料依据与使用边界

List the evidence sources used, including the Career Evidence Package, latest resume, and any high-value clarifications. State major exclusions, unresolved uncertainty, attribution caveats, and the boundary that file existence does not prove personal authorship.

## Writing Rules

- Write with evidence-based caution.
- Do not overstate personal ownership.
- Use project names, dates, or artifact names when the user permits.
- Mark uncertainty directly instead of hiding it.
- Keep `unknown / not evidenced` separate from capability gaps.
- Keep under-documented long-term experience separate from nonexistent capability.
- Distinguish long-term career throughline from currently strongest-evidenced capabilities.
- State both before finalizing core positioning; if they differ, explain their relationship instead of choosing only the better-documented stage.
- Never equate strongest-evidenced capability with core career positioning by default.
- Include capability gaps only when supported by explicit contrary evidence or clear target-role mismatch.
- Prefer practical career language over academic assessment language.
- Do not write fixed industry, role, or capability assumptions into the report structure.
